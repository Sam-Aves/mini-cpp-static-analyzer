# Mini C++ Static Analyzer

A mini compiler-design project written in C++ that performs:

- Lexical Analysis
- Syntax Analysis
- Semantic Analysis
- Runtime Error Checks

## Features

- Token generation
- Keyword and identifier recognition
- String and character literal handling
- Operator and separator detection
- Symbol table management
- Type checking
- Undeclared variable detection
- Division by zero detection
- Array bounds checking
- Bracket matching using stack

## Technologies Used

- C++
- STL
- Stack
- Map
- Vector
